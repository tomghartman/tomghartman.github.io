Privacy policy – Agent Control

Last updated: 23 October 2026

Agent Control is a private application that runs only on its owner's own computer. Only the owner uses it.

What data it accesses

When the owner signs in with Google, Agent Control asks for these permissions on the owner's own Gmail account:

  • gmail.readonly: read messages and settings (for example send-as addresses), to check context and prepare replies.
  • gmail.compose: create drafts and send messages. A message is only sent after the owner approves it, one message at a time.

How the data is stored and shared

  • Sign-in tokens and keys are stored in the macOS Keychain on the owner's computer.
  • Mail content is processed on that computer, and with AI services the owner has chosen to use. It is not sold, not used for advertising and not shared with anyone else.
  • There is no server run by Agent Control that receives Gmail data.

Google API Services User Data Policy

Agent Control's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke access at any time at myaccount.google.com/permissions, or remove the integration in Agent Control. Removing it deletes the stored tokens from the Keychain.
