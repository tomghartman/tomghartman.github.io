Agent Control

Agent Control is a personal dashboard that runs locally on its owner's Mac. It lets the owner follow AI agents, hand out tasks and review results.

With the owner's permission it connects to their own Gmail account through the Gmail API to read mail and prepare drafts. A message is only sent after the owner approves it, one message at a time.

It is a private tool for one person and is not offered to the public.
